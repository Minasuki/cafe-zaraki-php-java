# ☕ Café Zaraki - Versión Escolar (PHP + Java)

Sistema de pedidos para cafetería desarrollado como proyecto escolar.

## 🛠️ Stack Tecnológico

- **Frontend**: HTML5, CSS3, JavaScript vanilla
- **Backend principal**: PHP 8.x con PDO
- **Servicio adicional**: Java (Spring Boot / Servlets)
- **Base de datos**: PostgreSQL 17 (servidor Debian en VM)
- **Servidor web**: Apache 2.4

## 📁 Estructura del Proyecto

- `backend-php/` - API REST en PHP
- `java-service/` - Servicio en Java (reportes / gestión)
- `frontend-html/` - Interfaz de usuario (cliente y empleado)
- `database/` - Scripts SQL (creación, permisos, datos de ejemplo)

## 🗄️ Base de Datos Compartida

Este proyecto comparte la base de datos `cafe_zaraki` con la versión JavaScript.
La administración se realiza en una VM Debian con PostgreSQL 17.

### Usuario de conexión
- **Usuario**: `app_php`
- **Base de datos**: `cafe_zaraki`
- **Host**: `127.0.0.1:5433` (redirección desde VirtualBox)
